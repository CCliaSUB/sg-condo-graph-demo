# Singapore Condo Price Graph Demo

Interactive map of a condominium property graph for Singapore rental and sale
prices, with held-out test-set predictions at 1-, 12- and 24-month horizons.
Predictions are model estimates for past observed months, not market quotations
or forecasts.

This repository is a generated deployment bundle (Dockerfile, API, built frontend
and trimmed data). It is deployed on Render from `render.yaml`.
